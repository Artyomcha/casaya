# Интеграция агентств: XML-фиды CRM

Инвентарь портала наполняется автоматически из выгрузок агентских CRM.
Со стороны агентства подключение — это одна ссылка, ручная работа не нужна.

## Поддерживаемые форматы

| Формат в API | CRM | Разборщик |
|---|---|---|
| `INMOVILLA` | Inmovilla | собственный (испанские имена полей, `cod_ofer`) |
| `KYERO` | Kyero XML v3 | базовый |
| `WITEI`, `MOBILIA`, `RESALES` | Witei, Mobilia, Resales Online | Kyero-совместимые |
| `CASAYA` | без CRM, ручная выгрузка | схема Casaya (см. ниже) |

Формат определяется автоматически по корневым тегам, но его можно задать явно.

Разборщики устойчивы к именам полей: каждое значение ищется по списку
синонимов (`ref` / `id` / `reference`, `price` / `precioinmo` / `precio_venta`
и т. д.), испанский формат чисел `259.000` понимается корректно.

## Как подключается агентство

1. `POST /api/agencies/register` — создаётся агентство, размещение бесплатно 12 месяцев.
2. `POST /api/feeds/preview` — **сухой прогон**: скачиваем фид, разбираем, показываем,
   сколько объектов загрузится и что именно не пройдёт. В базу ничего не пишется.
3. `POST /api/feeds` — фид сохраняется и сразу синхронизируется.
4. Дальше планировщик опрашивает фид каждые `intervalMin` минут (по умолчанию 60).

В кабинете (`/pro/cabinet`) всё это доступно через интерфейс.

## Что делает синхронизация

- **Новый `externalId`** → создаётся объект.
- **Известный `externalId`** → сравнивается SHA-1 исходного узла XML.
  Не изменился — объект не переписывается, только отмечается «всё ещё в выгрузке».
- **Пропал из выгрузки** → объект переводится в `ARCHIVED`, а не удаляется:
  на него могут быть отклики и история.

Каждый прогон пишется в `FeedRun`: `parsed / created / updated / archived / skipped`.
Ошибка одного фида не останавливает остальные.

## Что отбрасывается

Объект не загружается, если у него нет идентификатора, цены, площади,
адреса или фотографий. Причина по каждому попадает в предпросмотр и в `FeedRun.skipped`.

## Координаты

`latitude` / `longitude` (или `latitud` / `longitud` у Inmovilla) переносятся
в объект как есть — по ним строится пин на карте поиска. Объект без координат
загрузится и будет в выдаче, но на карте не появится.

## Бейдж Verificado

Импорт из фида **никогда** не ставит `verified: true`. Бейдж выдаётся только
после проверки nota simple и видео-тура по чек-листу — в этом смысл
позиционирования «solo pisos reales».

## Безопасность

Фид — это URL, который присылает внешняя сторона, поэтому:

- разрешены только `http` / `https`;
- внутренние адреса (`localhost`, `10.*`, `192.168.*`, `169.254.*`) заблокированы —
  защита от SSRF; снимается только флагом `FEED_ALLOW_PRIVATE=true` для локальной разработки;
- таймаут 30 секунд, ограничение размера 64 МБ.

## Схема Casaya

Для агентств без CRM:

```xml
<casaya>
  <listing>
    <externalId>A-1042</externalId>
    <title>Вилла с бассейном</title>
    <description>…</description>
    <address>Sierra Blanca, Марбелья</address>
    <city>Марбелья</city>
    <kind>house</kind>
    <price>485000</price>
    <area>170</area>
    <bedrooms>4</bedrooms>
    <bathrooms>3</bathrooms>
    <seaView>1</seaView>
    <yearBuilt>2019</yearBuilt>
    <features><feature>Бассейн</feature></features>
    <images><image><url>https://…/1.jpg</url></image></images>
    <lat>38.5990</lat><lng>-0.0520</lng>
  </listing>
</casaya>
```
